# Security policy

## Report a vulnerability privately

Use GitHub's **Report a vulnerability** form in the Security tab of the
repository the problem is in. For anything in the browser itself, use
[Crest's form](https://github.com/pauljoda/Crest/security/advisories/new).
Please do not open a public issue or post on Reddit about a suspected
vulnerability.

Include what is affected, the boundary you expected to hold, reproducible steps
or a proof of concept, and the impact you believe is possible. Remove browsing
data, account tokens, passwords, private URLs and other personal information
before attaching evidence.

Crest's own [security policy](https://github.com/pauljoda/Crest/blob/main/SECURITY.md)
covers supported versions and scope for the browser.
