# Support

- **Questions, ideas and compatibility reports:** [r/CrestBrowser](https://www.reddit.com/r/CrestBrowser).
  Reddit is public, so remove passwords, account details, private URLs and
  browsing history before posting.
- **Reproducible bugs:** [Crest issues](https://github.com/crest-browser/Crest/issues/new/choose),
  with the Crest version, platform, steps, expected result and actual result.
- **Security vulnerabilities:** the private form described in [SECURITY.md](SECURITY.md),
  never a public issue.
- **Guides:** [crestbrowser.com/guides](https://crestbrowser.com/guides/).
