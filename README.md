# crest-browser/.github

The Crest Browser organization's public profile and the community files every
repository here falls back on when it has none of its own.

- `profile/README.md` is the page at [github.com/crest-browser](https://github.com/crest-browser).
- `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` and `FUNDING.yml` apply to
  any repository in the organization without its own copy. Crest keeps its own,
  and those take precedence there.
